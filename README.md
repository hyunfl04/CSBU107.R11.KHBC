# CSBU107.R11.KHBC - Object-Oriented Programming (OOP) Lab Work

## 📌 Description
This repository contains the source code, laboratory assignments, and practical exercises completed as part of the **Object-Oriented Programming (CSBU107.R11.KHBC)** course. 

The primary objective of this repository is to track learning progress, demonstrate core Object-Oriented Programming (OOP) principles, and maintain clean, structured code implementations for academic coursework.

## 🔑 Key Concepts Covered
- **Encapsulation:** Data hiding, access specifiers, getters/setters.
- **Inheritance:** Class hierarchies, base/derived classes, code reusability.
- **Polymorphism:** Method overloading/overriding, virtual functions, dynamic binding.
- **Abstraction:** Abstract classes, interfaces, pure virtual functions.
- **Object-Oriented Design:** Class relationships, memory management, and clean code practices.
